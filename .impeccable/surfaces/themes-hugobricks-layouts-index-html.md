## Direction contract

THESIS: Every page is a lit kitchen with a table set for one more guest. Refuses the Pflegeheim template of stock smiling seniors, icon-card grids, and teal trust badges.

OWN-WORLD: Linen #EFE6D8 and oat grounds, coal-brown #2B221C ink, one brick-red door (#A8432F family) for the act of calling, lamp ochre for warmth and numbers, moss green for garden and trust bands. Vollkorn headings, Atkinson Hyperlegible Next body. Linen place-cards with soft rounded corners set on warm photography; honest captions on every photo; prices as a ruled household note with totals underlined twice.

STORY: Relief (not a Heim), recognition (the real kitchen, the real people), understanding (970 € in plain numbers, five steps), trust (Robin, Julianne, Guilia), then a warm open door: phone, mail, visit.

FIRST VIEWPORT: Full-bleed warm kitchen photo. Transparent header over it: cream Vollkorn wordmark left, cream nav right, brick-red "Anrufen" button far right. Lower-left linen place-card (~44% wide) with the headline, a two-line lede, a brick-red phone button and an ochre-brown "Besuch vereinbaren" link.

FORM: Der gedeckte Küchentisch, my own list position 1 (IMPECCABLE'S PICK over roll position 7), seed key 66ffd8dc. Signature motion: the place-card settles in once like a door easing open; nothing else animates on load.
